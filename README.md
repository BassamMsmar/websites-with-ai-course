# بناء ونشر المواقع بالذكاء الاصطناعي

الموقع التفاعلي لمادة جامعية من 10 محاضرات. مبني بـ HTML و CSS و JavaScript خالص، بلا أدوات بناء ولا مكتبات، ليكون نموذجًا حيًا لما يتعلمه الطالب.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج خادمًا.

للمعاينة عبر خادم محلي (اختياري):

```bash
python -m http.server 5173
```

ثم افتح `http://localhost:5173`.

## الميزات

- ثلاثة تبويبات لكل درس (محتوى / عملي / اختبار) مع تذكّر التبويب المفتوح.
- محرك اختبارات: 10 أسئلة، تصحيح فوري، شرح لكل إجابة، نتيجة نهائية، إعادة المحاولة.
- تتبّع التقدّم في `localStorage`: الدروس المكتملة، الدرجات، نسبة الإنجاز، سلّم النشر.
- عربي RTL كامل بخط IBM Plex Sans Arabic، وضع ليلي ونهاري، متجاوب، وقابل للطباعة.

## إضافة أسئلة لدرس

في نهاية ملف الدرس، عرّف `window.QUIZ_DATA` كمصفوفة:

```js
window.QUIZ_DATA = [
  {
    scenario: "حالة عميل",           // اختياري
    q: "نص السؤال",
    options: ["أ", "ب", "ج", "د"],
    answer: 1,                       // فهرس الإجابة الصحيحة (يبدأ من 0)
    explain: "شرح يظهر بعد الإجابة"
  }
];
```

## جدول فتح الدروس

يُفتح درس واحد كل أسبوع، يوم الاثنين، قبل المحاضرة بيوم. الدروس التي لم يحن موعدها محجوبة: صفّها في الرئيسية لا يُنقر، وعنصرها في القائمة الجانبية باهت، ومن يكتب رابطها يدويًا يرى شاشة «لم يُفتح بعد» مع تاريخ الفتح.

كل الإعداد في مكان واحد: `SCHEDULE` أعلى [assets/js/app.js](assets/js/app.js).

```js
const SCHEDULE = {
  FIRST_UNLOCK: [2026, 9, 14],  // فتح الدرس الأول: الاثنين 14 سبتمبر (المحاضرة الثلاثاء 15)
  EVERY_DAYS: 7,                // درس كل أسبوع
  UNLOCK_ALL: false,            // true = افتح كل الدروس فورًا
  UNLOCK_UP_TO: 0,              // افتح حتى هذا الرقم يدويًا. 0 = تجاهله
  SHIFT: {}                     // { 4: 7 } يؤخّر الدرس الرابع أسبوعًا
};
```

| الحالة | ما تعدّله |
|---|---|
| تأجّلت محاضرة أسبوعًا | `SHIFT: { 5: 7 }` يؤخّر الدرس الخامس وحده |
| المراجعة قبل الاختبار النهائي | `UNLOCK_ALL: true` |
| تريد فتح درس قبل موعده | `UNLOCK_UP_TO: 6` |
| تغيّر تاريخ بداية المادة | `FIRST_UNLOCK` |

بعد أي تعديل: `git add . && git commit -m "..." && git push`، ويظهر الأثر على الموقع خلال دقيقة. جدول المواعيد الكامل يظهر للطلاب في [صفحة «عن المادة»](pages/about.html).

**حدود الحجب:** الموقع ثابت، فالحجب يحدث في المتصفح ويعتمد على ساعة جهاز الطالب. من يفتح كود الصفحة أو يغيّر تاريخ جهازه يستطيع تجاوزه. الغرض تنظيم مسار المجموعة، لا الحماية. هذه بالضبط حدود المواقع الثابتة التي يشرحها الدرس 8.
