# بناء ونشر المواقع بالذكاء الاصطناعي

الموقع التفاعلي لمادة جامعية من 10 محاضرات. مبني بـ HTML و CSS و JavaScript خالص، بلا أدوات بناء ولا مكتبات، ليكون نموذجًا حيًا لما يتعلمه الطالب.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج خادمًا.

للمعاينة عبر خادم محلي (اختياري):

```bash
python -m http.server 5173
```

ثم افتح `http://localhost:5173`.

## بنية الملفات

```
/
├── index.html              الرئيسية: نظرة عامة + سلّم النشر + قائمة الدروس

│   └── lesson-01.html … lesson-10.html
├── pages/
│   ├── about.html          عن المادة والمخرجات

│   └── resources.html      الأدوات والروابط
├── assets/
│   ├── css/style.css       نظام التصميم كاملًا بمتغيّرات CSS
│   ├── js/app.js           التبويبات + التقدّم + الوضع الليلي + القائمة الجانبية
│   └── js/quiz.js          محرك الاختبارات
├── PRODUCT.md              السياق الاستراتيجي للتصميم
├── DESIGN.md               النظام البصري (ألوان، خطوط، مكوّنات)
└── course-plan.md          خطة المادة المعتمدة
```

## الميزات

- ثلاثة تبويبات لكل درس (محتوى / عملي / اختبار) مع تذكّر التبويب المفتوح.
- محرك اختبارات: 10 أسئلة، تصحيح فوري، شرح لكل إجابة، نتيجة نهائية، إعادة المحاولة.
- تتبّع التقدّم في `localStorage`: الدروس المكتملة، الدرجات، نسبة الإنجاز، سلّم النشر.
- عربي RTL كامل بخط IBM Plex Sans Arabic، وضع ليلي ونهاري، متجاوب، وقابل للطباعة.

## إضافة أسئلة لدرس

في نهاية ملف الدرس، عرّف `window.QUIZ_DATA` كمصفوفة:

```js
window.QUIZ_DATA = [
  {
    scenario: "حالة عميل",           // اختياري
    q: "نص السؤال",
    options: ["أ", "ب", "ج", "د"],
    answer: 1,                       // فهرس الإجابة الصحيحة (يبدأ من 0)
    explain: "شرح يظهر بعد الإجابة"
  }
];
```
